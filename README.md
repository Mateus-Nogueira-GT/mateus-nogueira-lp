# Landing page — Mateus Nogueira

Landing page com duas jornadas de mesmo peso: projetos personalizados para empresas, realizados pela Active IA, e mentoria individual para profissionais que querem trabalhar com IA.

## Rodar localmente

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Integrações pendentes para produção

- Google Calendar/Meet para o agendamento empresarial.
- Destino seguro para as aplicações da mentoria e contato pelo WhatsApp.
- URL oficial do Instagram.
- Prints de depoimentos autorizados, com dados pessoais ocultados quando necessário.

Os formulários atuais são demonstrações locais e não enviam dados.
